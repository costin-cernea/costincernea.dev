# Costin Cernea - Portfolio

Personal presentation website highlighting my projects, skills, and focus on DevOps, infrastructure, and automation.

## 🛠 Tech Stack

- **React** + **Vite** - Fast, modern frontend tooling
- **Tailwind CSS** - Custom dark mode & glassmorphism UI
- **Framer Motion** - Micro-animations, glowing cursor effects, and transitions

## 🚀 Running Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/costin-cernea/costin-cernea-portfolio.git
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```
